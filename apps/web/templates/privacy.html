GROONA

개인정보처리방침 초안

출시 전 반드시 실제 사업자 정보와 처리 현황에 맞춰 법률 검토 후 확정하십시오.

1. 기본 원칙

GROONA는 서비스 제공에 필요한 최소한의 개인정보를 처리하며, 보호자 계정 아래 자녀 프로필을 관리하는 구조를 사용합니다.

2. 예정 처리 항목

보호자: 이메일, 인증정보, 서비스 이용기록. 자녀 프로필: 보호자가 입력한 별칭, 연령, 생활권, 관심 성장영역. 선택 기능: 위치정보, 푸시 토큰.

3. 아동 개인정보

만 14세 미만 아동의 개인정보 처리에 동의가 필요한 경우 법정대리인 동의 및 확인 절차를 구현해야 합니다. 아동이 이해하기 쉬운 언어의 안내를 별도로 제공합니다.

4. 권리와 삭제

이용자는 앱의 계정 삭제 기능을 통해 계정과 연결 데이터를 삭제 요청할 수 있도록 설계합니다.

5. 광고

초기 버전은 아동 프로필을 이용한 맞춤형 광고를 사용하지 않는 것을 기본 원칙으로 합니다.
